# BINGO

2~3명이 함께하는 주제 빙고. 주제는 모두에게 공유되고, 빙고판은 각자 따로 채워요.

## 게임 방법

1. 한 명이 **새 방 만들기** → 위쪽 방 코드를 눌러 초대 링크를 친구에게 보내요.
2. 누구든 **주제**를 적으면 모두에게 똑같이 보여요. 고민되면 **🎲 추천**. 목표 줄 수(1~5줄)도 정할 수 있어요.
3. 각자 5×5 칸을 채우고 **준비 완료**. (고치고 싶으면 **준비 취소**, 귀찮으면 **✨ 자동**으로 주제 단어 채우기)
   - 누군가 먼저 준비하면 나머지 사람에게 **1분 30초** 타이머가 돌아요. 시간이 끝나면 빈 칸이 주제 단어로 자동으로 채워지고 바로 시작해요.
4. 모두 준비되면 게임 시작! 빙고판은 잠기고, 내 차례에 **빙고판 칸을 눌러서** 그 단어를 불러요.
5. 불린 단어가 내 판에 있으면 칸이 칠해지고, 한 줄이 완성되면 빙고 줄이 그어져요.
6. 목표 줄 수를 먼저 채운 사람이 우승. 동시에 채우면 공동 우승이에요.
7. 누가 너무 느리면 **👉 쪼기**! (내가 준비됐는데 아직 준비 안 한 사람, 또는 게임 중 차례인 사람) 상대 화면에 재촉하는 말풍선이 우르르 떠요.

## 구조

- React + Vite, 서버 없음
- 방장 브라우저가 게임 규칙을 처리하고, 참가자는 WebRTC(PeerJS)로 방장과 직접 연결돼요.
  - 방장이 나가면 방이 닫혀요.
  - 새로고침하면 같은 방으로 다시 들어가요 (방장도 방 상태가 복구됨).
  - 접속 중개는 PeerJS 공용 서버를 써요.
- 다른 사람에게는 내 빙고판 내용을 보내지 않아요.

```
src/
  game/logic.js        게임 규칙 (방장이 실행)
  game/logic.test.js   규칙 테스트
  game/autofill.js     주제 추천, 위키데이터/위키백과로 빈 칸 자동 채우기
  net/host.js          방장 세션
  net/guest.js         참가자 세션
  net/useBingo.js      화면에서 쓰는 React 훅
  components/          화면 (입장, 방, 빙고판)
```

## 로컬 실행

```bash
npm install
npm run dev
```

같은 PC에서 브라우저 탭 두 개를 열면 2인 테스트가 돼요. 같은 와이파이의 폰으로도 터미널에 나온 Network 주소로 접속할 수 있어요.
