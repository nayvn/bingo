# BINGO 놀이방

2~3명이 함께하는 놀이방. 방 하나에서 **빙고 · 초성퀴즈 · 그림맞히기**를 골라 가며 해요.

## 시작하기

1. 한 명이 **새 방 만들기** → 위쪽 방 코드를 눌러 초대 링크를 친구에게 보내요.
2. 방 위쪽 탭에서 할 게임을 골라요. 대기실에서는 누구나 바꿀 수 있고, 바꾸면 다들 다시 준비해요.
3. 모두 **준비 완료**를 누르면 시작! 게임이 끝나면 **다시 하기**로 대기실에 돌아와 다른 게임을 골라도 돼요.
4. 누가 너무 느리면 **👉 쪼기**! (내가 준비됐는데 아직 준비 안 한 사람, 빙고에서 차례인 사람, 그림 그리는 사람) 상대 화면에 재촉하는 말풍선이 우르르 떠요.

## 🎯 빙고

1. 누구든 **주제**를 적으면 모두에게 똑같이 보여요. 고민되면 **🎲 추천**. 목표 줄 수(1~5줄)도 정할 수 있어요.
2. 각자 5×5 칸을 채우고 **준비 완료**. (고치고 싶으면 **준비 취소**, 귀찮으면 **✨ 자동**으로 주제 단어 채우기)
   - 누군가 먼저 준비하면 나머지 사람에게 **1분 30초** 타이머가 돌아요. 시간이 끝나면 빈 칸이 주제 단어로 자동으로 채워지고 바로 시작해요.
3. 빙고판은 잠기고, 내 차례에 **빙고판 칸을 눌러서** 그 단어를 불러요. 먼저 시작하는 사람은 판마다 돌아가요.
4. 불린 단어가 내 판에 있으면 칸이 칠해지고, 한 줄이 완성되면 빙고 줄이 그어져요.
5. 목표 줄 수를 먼저 채운 사람이 우승. 동시에 채우면 공동 우승이에요.

## 🔤 초성퀴즈

- 분야(랜덤/음식/동물/나라…)와 초성을 보고 단어를 맞혀요. 예) 동물 · ㄱㅇㅇ → 고양이
- 가장 먼저 맞힌 사람만 점수를 받고 바로 다음 문제로 넘어가요. 한 문제에 30초.
- 10초마다 글자가 하나씩 열려요. 점수는 3 → 2 → 1점으로 줄어요.
- 같은 분야에 초성이 같은 단어가 또 있으면 그것도 정답으로 쳐요.
- 문제 수는 5/10/15개 중에서 골라요. 끝났을 때 점수가 가장 높은 사람이 우승.

## 🎨 그림맞히기

- 한 명이 제시어를 그리면 나머지가 채팅으로 맞혀요. 그리는 사람은 돌아가면서 바뀌어요 (한 사람당 1~3번).
- 한 번에 80초. 40초가 지나면 초성, 60초가 지나면 첫 글자가 힌트로 나와요.
- 먼저 맞히면 +3점, 다음 사람은 +2점. 그린 사람도 맞힌 사람 1명당 +1점.
- 그리는 사람은 색 8가지, 굵기 3가지, 지우개, 되돌리기, 모두 지우기를 쓸 수 있고, 제시어가 어려우면 두 번까지 바꿀 수 있어요.

## 구조

- React + Vite, 서버 없음
- 방장 브라우저가 게임 규칙을 처리하고, 참가자는 WebRTC(PeerJS)로 방장과 직접 연결돼요.
  - 방장이 나가면 방이 닫혀요.
  - 새로고침하면 같은 방으로 다시 들어가요 (방장도 방 상태가 복구되고, 그리던 그림도 다시 받아요).
  - 접속 중개는 PeerJS 공용 서버를 써요.
- 다른 사람에게는 내 빙고판, 퀴즈 정답, 그림 제시어를 보내지 않아요.
- 초성퀴즈·그림맞히기 단어는 직접 고른 목록을 써요 (인터넷·AI 없이 바로 됨).

```
src/
  game/logic.js        방 규칙 + 빙고 (방장이 실행)
  game/quiz.js         초성퀴즈 규칙
  game/draw.js         그림맞히기 규칙
  game/words.js        초성퀴즈·그림맞히기 단어 목록
  game/common.js       초성 뽑기, 점수 등 공통 도구
  game/*.test.js       규칙 테스트
  game/autofill.js     빙고 주제 추천, 위키데이터/위키백과로 빈 칸 자동 채우기
  net/host.js          방장 세션
  net/guest.js         참가자 세션
  net/inkStore.js      그림판 내용 (조각 단위로 주고받음)
  net/useBingo.js      화면에서 쓰는 React 훅
  components/          화면 (입장, 방 뼈대, 빙고판, 그림판)
  components/games/    게임별 화면
```

## 로컬 실행

```bash
npm install
npm run dev
```

같은 PC에서 브라우저 탭 두 개를 열면 2인 테스트가 돼요. 같은 와이파이의 폰으로도 터미널에 나온 Network 주소로 접속할 수 있어요.

## 배포

`main` 브랜치에 push하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 자동으로 해요.

처음 한 번만: 레포 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿔 주세요.
